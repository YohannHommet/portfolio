// walspool: zero-alloc in-process WAL & OTel hub
type Engine struct {
    ringBuf   *ring.Buffer   // Lock-free circular segment
    diskSpool *wal.Writer    // Crash-resilient mmap segment
    stream    chan otlp.Span
}

func (e *Engine) Push(span otlp.Span) error {
    if e.ringBuf.TryPush(span) {
        return nil // 0 heap allocations
    }
    return e.diskSpool.SyncReplay(span) // Sub-ms replay
}

    cipher: ChaCha20Poly1305,

}

impl PeerSession {
    pub async fn handshake(pw: &[u8]) -> Result<Self, ProtocolError> {
        let key = spake2::exchange(pw).await?;
        let stream = transport.open_bi().await?;
        Ok(Self::new(stream, key))
    }

Principe Directeur

Modules Profonds & Contrôle Zéro-Allocation

Les meilleurs systèmes masquent une complexité majeure derrière des APIs minimalistes. Dans mes moteurs Go et protocoles Rust, chaque structure est conçue pour minimiser la pression sur le garbage collector, privilégier la localité de cache et résister aux crashs machine sans altération d'état.

  • Zéro allocation sur le chemin critique : Utilisation de ring-buffers pré-alloués et mmap pour absorber les pics de trafic.
  • Résilient aux pannes : Rejeu sub-milliseconde via Write-Ahead Log synchronisé sur disque sans perte d'événements.
  • Sécurité cryptographique par défaut : Chiffrement direct point-à-point, échanges de clés SPAKE2 (RFC 9382) et hachage streaming BLAKE3.

Système & Télémétrie

walspool

Go

Moteur in-process de Write-Ahead Log (WAL) et concentrateur OpenTelemetry en Go. Absorbe les rafales de télémétrie sur disque en cas de coupure amont avec zéro allocation sur le chemin chaud pour éliminer les risques d'OOM.

  • Double buffer circulaire en mémoire et segmentation disque mmap
  • Rejeu crash-résilient sub-milliseconde sans pression sur le GC
  • Prévient les effondrements de service sous pics d'ingestion massifs

Protocole Réseau P2P

wisp

Rust

Moteur de transfert direct pair-à-pair chiffré sur QUIC et TLS 1.3 éphémère. Authentification mutuelle par mot de passe via SPAKE2 (RFC 9382) et intégrité de flux validée par BLAKE3 streaming.

  • Transport direct 1-RTT chiffré via QUIC (sans transit serveur non sécurisé)
  • Échange de clé authentifié par mot de passe fort (SPAKE2)
  • Relais de rendez-vous aveugle et sans état propulsé par Axum
